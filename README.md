# اختبار القانون التجاري (MCQ)

تطبيق اختبارات اختيار من متعدد لمادة القانون التجاري، 130 سؤالاً.

- تخلط الأسئلة وترتيب الخيارات في كل محاولة
- وضع تدريب (إجابة فورية) ووضع امتحان
- مؤقت اختياري، ومراجعة للأخطاء، وحفظ النتائج على الجهاز

التشغيل: افتح `index.html` في أي متصفح.

تصميم: عبد الله مصطفى
